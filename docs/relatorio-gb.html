2. Funcionalidades JavaScript Implementadas

2.1 Menu Hambúrguer via addEventListener ✅ (feito no GA, migrado para JS externo)

O menu hambúrguer responsivo para mobile foi implementado na entrega anterior com onclick inline. Nesta entrega, foi migrado para um arquivo JS externo (js/main.js) usando addEventListener, seguindo boas práticas de separação de responsabilidades.

Evento utilizado: click | Elemento: .menu-toggle | Resultado: toggle da classe active no elemento .main-nav

2.2 Validação do Formulário de Contato com Feedback Visual

O formulário da página contato.html passou a ter validação em JavaScript com feedback visual imediato: bordas vermelhas nos campos inválidos, mensagens de erro por campo e mensagem de sucesso ao enviar corretamente.

Técnicas: Manipulação do DOM, addEventListener('submit'), classList.add/remove, criação dinâmica de elementos de erro

2.3 Formulário Funcional com Envio de E-mail

Ao enviar o formulário de contato, os dados são enviados para contatodevblog@gmail.com via integração com serviço de e-mail. O remetente recebe uma resposta automática confirmando o recebimento da mensagem.

2.4 Modo Claro/Escuro com localStorage

Um botão de toggle no header permite ao usuário alternar entre tema claro e escuro. A preferência é salva no localStorage do navegador, persistindo entre sessões.

API utilizada: localStorage | Método: localStorage.setItem/getItem('theme') | Resultado: tema salvo entre visitas

2.5 Filtro de Artigos por Categoria (Pedro)

Na página de categorias e na home, botões de filtro (Todos / Web / Mobile / IA / Segurança / DevOps) permitem filtrar os cards de artigos via manipulação do DOM, sem recarregar a página.

3. Biblioteca Utilizada — AOS (Animate on Scroll)

O que é o AOS?

AOS (Animate on Scroll) é uma biblioteca JavaScript leve que adiciona animações de entrada aos elementos da página conforme o usuário rola o conteúdo. Foi integrada via CDN, sem necessidade de instalação.

Justificativa da escolha

O AOS foi escolhido por ser leve, fácil de integrar e melhorar a experiência do usuário sem comprometer a performance. Com apenas dois arquivos (CSS + JS) carregados via CDN e atributos data-aos no HTML, é possível adicionar animações profissionais com mínimo esforço.

Como foi integrado

  • CSS adicionado no <head> de todas as páginas via CDN: https://unpkg.com/aos@2.3.4/dist/aos.css
  • JS adicionado antes do </body> de todas as páginas: https://unpkg.com/aos@2.3.4/dist/aos.js
  • Inicializado com AOS.init()
  • Atributo data-aos="fade-up" adicionado nos cards de artigos, ferramentas, equipe e seções principais
Páginas com AOS: index.html, categorias.html, ferramentas.html, sobre.html, contato.html, artigo.html, artigo-ia.html, artigo-mobile.html, artigo-seguranca.html, artigo-docker.html, artigo-python.html
